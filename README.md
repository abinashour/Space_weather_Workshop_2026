 ## Dataset Description

The dataset folder is divided into two different dates. Each date contains space-weather-related data that will be used in this practical activity.

The provided data include:

1. Solar images from:
   - SDO/HMI continuum
   - SDO/AIA 193 Å
   - SOHO/LASCO C3

2. GOES X-ray flux data in W/m²

3. Kp index data
